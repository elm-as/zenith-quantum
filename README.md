## 🎯 VISION
**Visualisation WebGL expérimentale de flux de consensus Blockchain.**

Une étude sur la représentation graphique de données distribuées asynchrones. Zenith transforme les événements de la blockchain en objets géométriques dynamiques, permettant d'observer la topologie de propagation du réseau.
